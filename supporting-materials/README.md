
# Supporting Materials

This folder contains evidence and materials supporting the Smart Campus 360 prototype submission.

## Add These Materials Before Submission

1. `screenshots/dashboard.png` — Dashboard showing sample campus resource summaries.
2. `screenshots/complaint-workflow.png` — A sample complaint submitted and displayed in the tracker.
3. `screenshots/api-docs.png` — FastAPI documentation page.
4. `architecture-diagram.png` — System architecture diagram.
5. `presentation.pdf` — Final hackathon presentation, if permitted.
6. `demo-video-link.md` — Link to the final prototype demonstration video.

## Evidence Guidelines

- Capture screenshots from the actual running prototype.
- Label simulated values clearly.
- Use fictional complaint details for demonstrations.
- Do not include passwords, API keys, or personal student information.
- Only include files that exist and accurately represent the project.

## Hardware and IoT Materials

The current prototype does not require a physical hardware circuit. If real sensors are added later, include relevant circuit diagrams, component lists, and integration instructions.
