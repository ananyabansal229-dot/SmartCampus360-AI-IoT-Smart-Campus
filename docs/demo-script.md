
# Smart Campus 360 — Prototype Demonstration Script

## 1. Introduction

"Smart Campus 360 is our AI + IoT smart-campus solution. It aims to bring resource monitoring, sustainability, navigation, and student services into one unified platform."

## 2. Dashboard

"Here, we display illustrative campus resource summaries and complaint statistics. These readings are sample values in the current prototype, not live sensor data."

## 3. Student Complaint Workflow

"A student can select an issue category, enter a campus location, describe the issue, and submit a complaint. The backend stores it in a local SQLite database."

## 4. Complaint Tracking

"The complaint appears in the tracker, where the demonstration user can mark it as resolved."

## 5. Future Vision

"Our roadmap includes real IoT sensors, AI-based anomaly detection, campus routing, library and canteen discovery, verified campus contacts, and event information."

## 6. Closing

"Smart Campus 360 aims to make campuses more connected, resource-efficient, and easier to navigate. We will expand the prototype through validated data, secure access, and tested integrations."
